= SmallRye Fault Tolerance documentation

The documentation is AsciiDoc, laid out like the Quarkus guides, and published on
https://smallrye.io/docs/smallrye-fault-tolerance/latest/[smallrye.io]. The site pulls it from this
repository: the `main` branch every night, and each release once it is tagged.

== Where things are

[cols="1,2"]
|===
|`src/main/asciidoc/**/*.adoc` |One page per file. The path is the page's address: `reference/retry.adoc` is published at `/docs/smallrye-fault-tolerance/<version>/reference/retry/`.
|`src/main/asciidoc/_nav.yml` |The sidebar: page order and sections. A new page must be added here.
|`src/main/asciidoc/_attributes.adoc` |Attributes every page includes. The release workflow updates the version attributes.
|`src/main/asciidoc/_partials/` |Fragments included by several pages, with `include::{partialsdir}/name.adoc[]`.
|===

== Writing a page

------
= Page title
:version-root: ../
include::{version-root}_attributes.adoc[]

Text...

== A section

Link to another page with xref:reference/retry.adoc[Retry], or to a section of it with
xref:reference/retry.adoc#a-section[]. Paths are relative to `src/main/asciidoc/`, whatever the
directory of the page.
------

* A page in a subdirectory sets `:version-root:` to `../` per level before including
  `_attributes.adoc`; a page at the top level just has `include::_attributes.adoc[]`.
* Section ids are Quarkus-style: `== Before Retry Actions` gets the id `before-retry-actions`.
* Diagrams (`[mermaid]`, `[plantuml]`) are rendered to SVG by smallrye.io.

== Previewing

Pull requests that change the documentation are rendered with the smallrye.io site by the
`Documentation` workflow, which fails on a broken include or a page that does not render. The
rendered site is attached to the workflow run as the `docs-smallrye-fault-tolerance` artifact.

To see the documentation the way smallrye.io shows it while you write it, run from this repository:

[source,bash]
----
./mvnw -Pdocs-preview
----

and open http://localhost:8080/docs/smallrye-fault-tolerance/main/. Pages and included examples are published again
when you save them; refresh the page. Only Java is needed: the profile runs the
https://github.com/smallrye/smallrye.github.io/tree/develop/tools/docs[smallrye.io docs tools]
with https://www.jbang.dev[JBang]. Where JBang is installed, `jbang docs-preview@smallrye/smallrye.github.io`
does the same, and takes options such as `--port` or `--site <a smallrye.github.io checkout>`
(see `--help`).
